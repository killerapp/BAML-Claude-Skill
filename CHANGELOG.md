# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0](https://github.com/FryrAI/BAML-Claude-Skill/compare/v1.1.0...v1.2.0) (2025-01-30)

### Features

* Two-phase MCP validation (baml_Examples → baml_Docs)
* Enhanced error recovery with auto-fix capabilities
* Observable MCP indicators for transparency
* Modernization of deprecated patterns from examples

### Documentation

* Added comprehensive CLAUDE.md for development guidance
* Updated metadata.yaml with full version history

## [1.1.0](https://github.com/FryrAI/BAML-Claude-Skill/compare/v1.0.0...v1.1.0) (2025-01-27)

### Features

* Added baml_Examples MCP server support
* Improved pattern matching accuracy
* Token optimization improvements

## [1.0.0](https://github.com/FryrAI/BAML-Claude-Skill/releases/tag/v1.0.0) (2025-01-25)

### Features

* Initial MVP release
* Core pattern matching (extraction, classification, RAG, agents)
* MCP integration with baml_Docs server
* Multi-tier caching strategy (4 tiers)
* Test and integration generation
* 5-layer validation pipeline
* Support for 6 languages (Python, TypeScript, Ruby, Java, Go, C#)
* Support for 10+ frameworks (FastAPI, Next.js, Rails, Spring Boot, etc.)
* 50-70% token optimization
* 95%+ compilation success rate
